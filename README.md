# Premium Portfolio Website

A cinematic, high-performance portfolio built with Next.js 15, Tailwind CSS v4, and GSAP.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP & Framer Motion
- **Language:** TypeScript
